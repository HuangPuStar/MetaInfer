# 第三次内联即落盘

**何时触发**：发现自己第二次、第三次内联敲同一段处理逻辑。

## 规则

- 同一段内联逻辑**第三次出现**时，抽成参数化脚本落盘（目标、轮数、输出路径做参数）。
- 脚本放固定路径供整个任务周期及后续会话复用；修改脚本优先于另写一份相似的。
- 命名反映功能而非日期，让"找它"的成本趋近于零。
- 一次性内联适合真正的探索；重复内联是工具债。

## 数据画像

- 语料中单文件脚本被复用上千次、环境脚本被引用数千次——"写一次跑千百次"是被验证的最高杠杆习惯；反之，内联胶水代码被一遍遍重敲，浪费上万次调用。

## 反模式信号

- 同一个"解析状态文件并打印进度"的内联代码，在会话里以微调版本出现十几次。
