# 多轮取中位，不信单次

**何时触发**：得到任何关键性能数字时。

## 规则

- 关键指标至少重复 3 轮，报告中位数；同时报告高位分位数（如 P90）——长尾问题藏在分位数里，不在均值里。
- 分离初始化与稳态：预热完成后的测量才计入统计。
- 单次结果与多轮中位数冲突时，以多轮为准，并排查那次异常的来源。
- 重复 N 次的测量由脚本内部循环完成、输出汇总到单个结果文件，不在会话层手动逐次跑。

## 反模式信号

- 用单次采样宣布 5% 提升，而测量噪声本身就有 5%。
- 首轮（含初始化）数据混进平均，报告值忽高忽低无法解释。
