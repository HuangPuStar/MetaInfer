# 新路径先冒烟

**何时触发**：即将使用没在此环境验证过的 API、库、构建方式、平台特性；或进入陌生环境。

## 规则

- 先用不超过几十行的最小独立用例验证新路径可用，通过后再接入主流程。
- 冒烟失败只损失几分钟；绕过它，错误会在完整流程里首次暴露，代价放大到整轮。
- 陌生环境（新机器/新栈/他人环境）下此纪律升级为强制。
- 冒烟结论（包括"此特性在该环境不可用"）写入记录，防止后续重复试探。

## 反模式信号

- 新用法直接写进主流程，完整运行时才报错，定位范围从几十行扩大到整个流程。
- 同一个"环境不支持 X"的结论在不同会话里被反复重新发现。
