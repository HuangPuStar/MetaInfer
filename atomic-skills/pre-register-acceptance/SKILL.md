# 预登记验收标准

**何时触发**：任务存在"怎样算做好"的判定问题——优化、修复、迁移、重构都适用。

## 规则

- 动手前写下量化通过/失败门槛与测量条件，**必须包含正确性门槛**，不只写性能门槛。
- 标准一经登记，中途不得悄悄放宽或重定义；确需变更须明示并说明原因。
- 交付时逐条对照**原始门槛**报告，不对照事后标准。
- 门槛覆盖全部目标场景，不挑容易的场景定制。

## 反模式信号

- 先跑出结果，再倒推"其实这也算达标"；用对自己有利的口径重定义成功。
- 验收时才发现"快了但算错了也算过吧"——正确性门槛从未被登记。
