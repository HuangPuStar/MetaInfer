# 收益枯竭即停

**何时触发**：迭代多轮、单轮收益越来越小的时候。

## 规则

- 事先声明终止条件：收益连续 N 轮低于噪声带，或总轮数达到上限——开工时定，不在沉没成本里定。
- 噪声带内的"提升"视为持平，不值得为之引入复杂度。
- 触发终止时输出"已试方向 + 各自结果"的完整矩阵，交还决策者。
- 停止是合格的结局；需要环境变更或高成本的新方向单独立项，不混入当前轮。

## 反模式信号

- 为 1% 的边际收益引入大段复杂代码，后续维护成本远超收益。
- 收益曲线早已躺平，仍在机械地"再试一个变体"。
