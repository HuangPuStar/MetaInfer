# 重跑前先查增量

**何时触发**：即将重跑任何昂贵步骤——参考实现、全量生成、长测试、大构建、数据导出。

## 规则

- 重跑前先找既有产物、完成旗标或指纹文件；核对输入自上次之后**是否真的变了**（内容/修改时间/哈希）。
- 输入没变就复用旧结果，并注明复用依据；反过来，结果来源不明时宁可重算一次，不用来源不明的数。
- 找不到"必须重跑"的证据就不重跑；禁止因"不确定跑没跑过"而重跑。
- 昂贵产物落盘时同步写指纹（输入哈希 + 时间戳）；下次先比指纹，相同直接复用结论。
- 中断恢复先盘点已完成项再续做，不重做。

## 反模式信号

- 参考实现没被改过却整套重跑——人类原话级纠偏："为什么要重新跑参考？参考你改了么？"
- 同一个长流程因为会话中断被从头再来。
