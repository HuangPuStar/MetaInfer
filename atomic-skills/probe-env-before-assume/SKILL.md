# 探测环境，不臆断

**何时触发**：需要任何"环境里有什么"的事实——装的库、可用工具、版本号、资源规格、目录内容。

## 规则

- 环境能力一律以**一条探测命令的实际输出**为准，不用训练记忆里的默认情况填空。
- 探测结果记录为事实；后续假设与探测冲突时，以探测为准重推结论。
- 术语与约定以项目内文档定义为准，不套通用理解（同一术语在不同项目里语义可能相反）。
- 被操作者给出事实纠正后（"当前系统没有 X"），撤销所有基于旧假设的结论再继续，不只是在下一条命令里改。

## 反模式信号

- 假设某库存在并据此解释失败原因，实际环境根本没装。
- 在一种运行时假设下写代码，另一环境下首次运行直接不可用。
