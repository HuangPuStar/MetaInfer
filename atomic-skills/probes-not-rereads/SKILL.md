# 缺的是探针不是阅读

**何时触发**：分析瓶颈/归因失败的过程中，发现自己反复在读代码。

## 规则

- 分析必须锚定在**本次测量数据**上；读代码是为了解释数据，不能替代数据。
- 第 3 次读同一段代码仍无新信息时，停下：缺的是探针，不是阅读量。
- 想知道什么就打点测什么（计时、计数器、中间产物导出），不靠脑内模拟执行。
- 阅读产出的每个结论都要能被一个测量证实或证伪。
- 分析 2 轮无新信息 → 带现状数据升级上报，不原地继续读。

## 反模式信号

- 侦察类动作占比畸高、测量类动作占比趋零——忙碌但没有新证据。
- "我再仔细看一遍代码"成为第 N 次的下一步。
