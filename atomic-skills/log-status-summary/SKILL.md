# 日志改读摘要

**何时触发**：对同一份日志反复执行 grep/tail 查状态。

## 规则

- 对同一日志 grep/tail 超过约 10 次时，改为**一个摘要命令**：输出三段——就绪状态 / 进度指标 / 错误行。
- 只在摘要显示状态变化时才看全文；摘要命令本身落盘复用。
- 判断"做完没有"读**单一状态文件/旗标文件**，不用逐个看文件时间戳、行数去"摸"。
- 摘要命令输出保持一行式，便于前后对比。

## 反模式信号

- 同一条"tail 日志 + cat 任务输出"的命令在会话里重复上百次。
- 靠 `ls -l` 看十几个文件的修改时间推断进度。
