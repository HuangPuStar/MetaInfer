# 分支符号完整

**何时触发**：写多模式/多分支代码、模板生成代码，或修改分支结构、增删模式开关。

## 规则

- 只在某模式分支里定义的变量/符号，使用前确认**所有分支路径**下都有定义——"未声明标识符"类构建错的第一大来源就是跨分支引用。
- 改分支或加模式开关前，全局搜索该符号的全部引用点，逐点确认可达。
- 生成的代码（模板展开/变体生成）逐个变体做构建检查，不让"另一个变体才用到"的符号漏网。
- 新引用的外部接口先确认在当前配置下真实存在（可选依赖路径、条件编译开关）。

## 反模式信号

- "只有模式 X 下才报未定义"的构建错，且在切换模式后才暴露。
- 模板变量拼写随生成器版本漂移，旧变体能编译、新变体不能。
