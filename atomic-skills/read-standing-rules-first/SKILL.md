# 先读常设规则

**何时触发**：会话/任务开始，进入他人维护的项目与工作区，或收到任务书/简报。

## 规则

- 第一步查找并**完整阅读**常设规则文件（项目说明、协作规范、任务书、约束文件），不是抽查开头几行。
- 任务书中的"背景/已试过/禁区/验收标准"段落优先级最高——它们是前人踩坑的结晶，跳过即重踩。
- 常设规则与临时指令冲突时，停下来询问，不自作主张取舍。
- 引用规则给出处（文件+位置），不凭印象转述。
- 长任务把关键约束摘录进工作记录，避免长会话中途遗忘。

## 反模式信号

- 跳过任务书直接动手，重复踩了任务书里已明确写过的坑。
- 被问"你没看任务书吗"。
