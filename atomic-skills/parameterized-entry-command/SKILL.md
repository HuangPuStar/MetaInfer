# 仪式入口化

**何时触发**：发现每条命令前都在重复拼装同样的前置步骤。

## 规则

- 重复的"启动仪式"——环境装载、资源占用检查、配置修改、执行——合并为**一个参数化入口命令**，内部完成装载、加锁与释放。
- 可变配置做成**模板变量**渲染，不在同一文件上用字符串替换来回贴——配置被反复改错位是高频事故。
- 每次渲染/构建的产物存档可回溯；执行记录写进运行目录。
- 入口命令失败时由它负责报告资源与环境状态，不把诊断责任推给调用方。

## 反模式信号

- 每条执行命令前都手动复制一遍"装载环境 → 查占用 → 再执行"三连。
- 配置文件被字符串替换改了几十轮，早已没人知道当前内容对应哪个版本。
