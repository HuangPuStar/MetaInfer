# 不变量不重查

**何时触发**：即将重复执行某个检查命令、或重读某个文档时。

## 规则

- 结果不变的检查（版本查询、导入冒烟、权限设置）同环境**只做一次**并记住结论；仅当环境重装/换容器后才重跑。
- 静态文件（规范、契约、模式定义）首次读后记要点；再次需要时先凭记录，用"路径 + 修改时间"判断是否变化，未变不重读全文。
- 重复执行前先问一句：这个命令的输出上次和这次会不一样吗？不会就别跑。
- 环境事实（探测结论、冒烟结论）集中记在一处，供整个任务周期引用。

## 反模式信号

- 同一环境里"导入冒烟"跑了两百次，每次输出逐字节相同。
- 同一份契约文档被原样重读十几次，每次都"完整阅读"。
