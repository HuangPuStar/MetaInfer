# 正确性门在性能测量之前

**何时触发**：即将对任何改动做性能测量、计时或基准对比。

## 规则

- 第一次计时之前，先通过与参考实现的正确性对比并记录差异度量。
- 正确性未通过则禁止计时；确需探测性能，结果必须标注"未过门，仅供参考"。
- 未过门的数据不得与已过门数据并列写进结论。
- 更快但错误的结果是失败，不是部分成功；报告性能前先报告正确性状态。
- 变体生成与正确性门放进同一循环：产出一个变体，立即排队一个门。

## 数据画像

- 含基准测量的轨迹中，约九成首次计时早于任何正确性检查——数值错误溜到后期才发现，整轮报废。
- 生成变体的轨迹中，相当比例全程没有任何正确性门。

## 反模式信号

- 用性能基准当正确性测试——它只看时间不看结果。
- "先看看快不快，对不对回头再说"。
