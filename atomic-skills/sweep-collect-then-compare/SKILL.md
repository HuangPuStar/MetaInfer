# 扫描后统一比较

**何时触发**：参数扫描、变体批量生成、多方案对比。

## 规则

- 一次生成全部变体，各自独立测量，统一汇总成表后再比较。
- 禁止边跑边凭手感切换方案——顺序偏差会制造假赢家。
- 比较在完全相同条件下进行，裁决标准预先写死，不允许事后自行解释通过条件。
- 负结果同样入表：全部低于阈值说明**变量空间选错**，回分析层重新假设，不是继续扫。
- 扫描空间要有理论依据：先归因瓶颈类型，再决定扫哪一维参数。

## 反模式信号

- 扫到第 5 个变体时凭印象"感觉这个不错"就切换主攻方向。
- 全部变体都差还在原空间里加大密度继续扫。
