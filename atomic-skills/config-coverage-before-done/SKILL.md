# 真实配置覆盖后才算完成

**何时触发**：即将宣称"改完了/测过了/可以交付了"。

## 规则

- 验证至少覆盖**真实配置**的关键开关组合；最小冒烟配置踩不到的路径，会在真实配置首次暴露。
- 列出改动影响的全部可选路径（开关、模式、环境分支），逐条确认有测试触达，或明确标记"未测"。
- 宣称完成前**清点结果集**：应做的每一组都在结果里；缺失的组列名说明原因，不静默跳过。
- 系统健康要主动确认（服务真的就绪、各部分真的在跑），不把"没报错"当"正常"。

## 反模式信号

- 小配置全绿，真实配置一跑就崩在没被触发的引用上。
- 被问"为什么这一组没有数据"时才发现结果集有洞。
