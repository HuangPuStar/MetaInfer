# 带数据升级

**何时触发**：触发止损线、需要操作者决策、或连续无进展时。

## 规则

- 升级时携带四件套：**现状数值**、**已尝试方向及各自结果**、**矛盾点**、**下一步候选建议**。
- 需要决策的选项以"已试矩阵 + 建议"形式呈现，不开放式提问（"我该怎么办"）。
- 禁止空手上报（"不行了"）；也禁止在无新信息时原地硬扛代替上报——多数无效坚持源于不愿上报。
- 升级是止损动作的收尾，不是失败。

## 反模式信号

- 上报只有情绪没有数据，决策者还得从头自己查。
- 明明已经试完所有候选，却继续烧时间不去打扰任何人。
