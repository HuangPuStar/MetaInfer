# 长等待后台化

**何时触发**：预计等待超过约 2 分钟的任何就绪/完成等待。

## 规则

- 长等待交给**后台脚本 + 状态文件**：前台只读状态，不阻塞在一条命令里。
- 后台轮询脚本幂等、可重入；启动新的之前先停掉旧的，防止多个轮询器并存。
- 状态文件记录三态：进行中 / 完成 / 失败（附关键日志位置）。
- 拉起 + 等待 + 确认合并成**一条命令**：命令返回即意味着"就绪"或"明确失败 + 关键日志尾部"，不在会话层手动分三步做。

## 反模式信号

- 会话被一个几分钟的轮询块整段占住，期间什么都做不了。
- 旧轮询器还在跑，新的又启动，状态文件被两个写入者打架。
