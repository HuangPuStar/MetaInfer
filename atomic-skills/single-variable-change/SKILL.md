# 一次只改一个变量

**何时触发**：任何调优、修复、A/B 对比、参数扫描的每一轮改动。

## 规则

- 每轮只允许一个变量变更；在实验记录里写明"本轮唯一变更"，这是归因依据。
- 修 bug 同样适用：修复引入新问题 → 回滚本次修复，而不是叠加第二个补丁。
- 多个候选都想试时，程序化生成单变量变体分别测量，不手工堆叠。
- 同一轮禁止同时改实现与比较方法/容差/测试输入——那会让"结果变化"失去解释。
- 变体命名携带变量与取值，保证任何结果可追溯到唯一差异。

## 反模式信号

- 同一轮 diff 里出现两处以上互不相关的修改。
- 结果变好/变坏但说不出是哪处改动导致，被迫整体回滚重来。
