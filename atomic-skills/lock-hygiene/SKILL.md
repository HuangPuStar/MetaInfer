# 锁纪律

**何时触发**：使用独占资源锁、文件锁、设备占用包装器。

## 规则

- 已持有锁的上下文里，**禁止再调用**会获取同一把锁的脚本或工具——嵌套获取是死锁的直接来源。
- 访问包装器检测到嵌套获取时**立即报错退出**，而非挂起等待；把死锁变成显式错误。
- 排队等锁的时间计入预算，并与真实执行时间**分开记录**——否则耗时归因会把"在排队"误判为"在干活"。
- 等锁超过预算时释放并上报，不死等。

## 反模式信号

- 外层包装器持锁、内层脚本再申请同一把锁，整个任务挂死到超时。
- 性能分析把等锁时间算进了执行时间，得出"慢"的错误结论。
