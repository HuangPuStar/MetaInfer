# 未定位机制不收工

**何时触发**：遇到报错想停下、或准备把问题草草交回时。

## 规则

- 报错是继续迭代的信号，不是终止信号；未定位机制前不宣布放弃。
- 浅解释不过关：因果断言必须能回答"**什么机制产生了这个观测**"；两边计算路径不同却解释"结果应该一样"，这类断言直接打回。
- 引入新设计元素（多一层转换、多一个概念）必须给必要性论证——"为什么要引入 X"要答得上来。
- 交回问题时必须附带：已排除项、剩余假设、下一步建议。
- 硬阻塞（权限/资源/外部依赖）除外——但需列出具体阻塞证据。

## 反模式信号

- "看起来是环境问题"就结案，没有排除过程。
- 结论经不起一句常识反问的推敲。
