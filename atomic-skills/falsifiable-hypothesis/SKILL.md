# 假设必须可证伪

**何时触发**：为任何改动形成"这样做应该会更好"的判断时。

## 规则

- 每次改动前写明四要素：**证据**（观测到什么）、**机制**（为什么改动会影响它）、**预期**（指标变化的方向和幅度）、**证伪条件**（看到什么就承认错了）。
- 无预期方向的假设禁止进入实现——否则结果差时无法区分"改坏了"和"本来就这样"。
- 改动后对照预期复盘：方向对不对、幅度够不够；预期落空即假设被否定，回分析层，不做解释性追加改动。
- 证据矛盾或不足时动手等于赌：回测量加探针。
- 因果断言必须能回答"什么机制产生了这个观测"；答不上来的解释不写进结论。

## 反模式信号

- "改了试试看"——没有预期，结果无论好坏都学不到东西。
- 两边输入不同却解释"结果应该一样"——经不起一句反问。
