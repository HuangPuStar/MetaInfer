# 证据反向即停

**何时触发**：新结果与当前路线的预期相反、或指标全面下滑时。

## 规则

- 新结果与预期相反时，先**停止生成同类数据**，回头分析已有数据——继续生产只会烧掉更多资源确认同一个坏消息。
- 继续原路线前，给出"为什么矛盾结果不否定该路线"的论证；给不出就换路线。
- 收到更高优先级目标时立即切换；原工作落好检查点与记录再走。
- 对比已有结果优先于再跑新实验——答案常常已经在数据里。

## 反模式信号

- 指标已全面下滑还在按原计划排队下一批测试。
- 新靶子已明确，旧任务仍在后台占着资源慢慢跑。
