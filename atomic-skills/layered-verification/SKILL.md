# 分层验证

**何时触发**：为改动设计验证结构。

## 规则

- 验证分层：**单元 → 模块 → 端到端**，每层独立可运行、可单独报告。
- 禁止只有数百行端到端巨石脚本——失败时无从定位，一次运行成本还高。
- 快照对比（哈希/diff）做第一道闸，先抓"意外改动了别处"。
- 对拍参考实现**刻意用更高精度或更简单的实现**，把差异集中到可解释范围，而不是拿两个近似实现互相比。
- 逐层导出中间产物做健康检查（形状、有限性），坏在一层就能拦住，不带病流到端到端。

## 反模式信号

- 失败证据全部来自端到端大脚本，无法判断错在哪一层。
- 两个实现各有近似误差，对拍结果永远"差一点"，谁都解释不了。
