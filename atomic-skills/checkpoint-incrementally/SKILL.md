# 一步一检查点

**何时触发**：任何包含多个独立改动的实验或修复序列。

## 规则

- 每个独立改动单独验证、单独落一个可恢复的检查点（版本提交/存档）。
- 失败时回退**当前这一步**，不在坏状态上叠加修补；替换一个、测一次、通过就固化，失败就回退并记录。
- 任何时刻能说清当前状态与最近良好态之间的全部差异。
- 回滚前先保全现场：实验改动导出为按假设编号命名的补丁入档，而不是直接销毁——实验现场是根因分析的证据。
- 报错的关键日志行**原样摘录**入档（含时间与上下文），不转述不概括。
- 确认无保留价值之前，禁止不可逆的清理。

## 反模式信号

- 堆叠多处实验性改动后失败，无法归因只能整体回滚，连带丢失有效部分。
- 回滚时把失败现场一并清空，事后想复盘已无证据。
