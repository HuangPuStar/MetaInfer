# 动手前先声明边界

**何时触发**：接到任何新任务、进入新环境/新仓库、开始调研/审计/分析类工作。

## 规则

- 动手前用一段话显式声明三件事：哪些路径/仓库**只读**、哪些资源（设备、服务、进程、网络）**禁触禁启**、唯一**可写**的目录白名单。
- 未声明的资源一律按只读处理；"顺手清理""顺手升级依赖"属于越界。
- 把边界声明放进首个回复，给操作者一个否决机会；被纠正边界后立即收缩，不辩解。
- 调研/审计任务默认零写操作；确需写时先申请授权再动。
- 结束时报告实际写过的完整路径清单，与声明对账。

## 反模式信号

- 分析任务进行到一半，发现"顺手"改了配置、升了依赖、删了"看起来没用"的文件——被分析对象已被污染，全部结论作废。
- 共享资源上未确认归属就终止/占用进程。
