# 进度外置

**何时触发**：任何多步骤长任务、可能跨会话/被中断的工作。

## 规则

- 每完成一个里程碑写一条**持久状态**（文件/清单）；长时间间隔或恢复后先读状态再行动，不凭记忆。
- 长任务后台运行、输出到文件、支持**断点续跑**；外部中断后从工件恢复，不重做全流程。
- 关键中间结果**先落盘再进入下一步**，不依赖会话内存——会话可能被压缩、断开或重启。
- 查子任务结果读汇总文件，不逐个摸文件系统。
- 遇外部中断（配额、网络、会话结束）先保存状态，再按同一协议恢复。

## 反模式信号

- 会话压缩/重启后，"之前做过什么"全部丢失，从头再来。
- 关键数据只存在于对话上下文里，产物文件里找不到。
