# 定位首个分歧点

**何时触发**：对拍/比较失败，需要报告与排查数值不一致。

## 规则

- 比较失败时输出**首个不一致元素**的索引、期望值、实际值——不是只报错误总数或错误率。
- 用首错位置推断错误类别再动手：靠前且规律 → 索引/步长问题；只在尾部 → 边界处理；特定批次元素 → 该路径特有逻辑。
- 深层/流水线结构中错误会向后传播：二分找**第一个**出错的节点——最后的坏节点没有诊断价值。
- 逐层/逐段导出中间产物检查首个异常出现点。
- 数值异常（非有限值等）先输出输入统计（最小/最大值、非有限值计数）与首个异常索引，再改代码。

## 反模式信号

- 汇报"117822/131072 个元素错了"却没有首错位置。
- 在最后一层输出上反复调，而错误早在前面某层就已发生。
