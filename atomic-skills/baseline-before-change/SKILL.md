# 无基线不动手

**何时触发**：开始任何优化、重构、替换、迁移工作之前。

## 规则

- 动手前固化未改动版本的关键指标与预期输出到**持久文件**（数值 + 输出摘要），不是聊天记录里的一行字。
- 基线本身报错或结果错误时，先修基线——坏基线上做的一切改动都不可判读。
- 基线与改动版必须在同条件下测量（规模、轮数、资源、环境一致）。
- 基线缺失时拒绝进入改动动作，先补基线；这个拒绝是止损，不是拖延。
- 基线数值随锚点一起入档，作为后续所有轮次的公共参照。

## 反模式信号

- 改完才发现没有对照数字，涨跌全靠感觉或单次印象。
- 引用的"之前的数据"其实来自另一套条件，无法判定本次是涨是跌。
