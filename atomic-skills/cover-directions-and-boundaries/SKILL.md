# 用例覆盖方向与边界

**何时触发**：为实现/变体设计正确性用例集。

## 规则

- 每个实现固定一组最小用例：**两个数据方向**（正反序/上下行/转置对称）、**首块与尾块边界**、**非对齐形状**。
- 单方向通过不得宣布正确——方向不对称是高频 bug 形态：同一实现一个方向全对、另一个方向大面积错。
- 边界（首块/尾块/掩码边缘/最后一个分块）单独构造用例，不靠常规用例顺带覆盖。
- 所有变体用**同一组**用例，不得各用各的测试；用例集本身入版本管理。

## 反模式信号

- "上行测过了"就宣布完成，下行一跑全错。
- 只测整除规模，非对齐尾部一上来就越界或读垃圾。
