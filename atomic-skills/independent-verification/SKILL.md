# 独立验证，不信自报

**何时触发**：接收任何结论——自己的记忆、他人或下游代理的汇报、日志里的声明。

## 规则

- 任何断言（自己的或别人的）默认**未证实**；接收结论的第一动作是找反例和证伪路径，不是找佐证。
- "已通过/已优化/已修复"须由**独立路径**复核：重跑最终产物、重读代码原文；不把日志里的声明当结果，把重跑的输出当结果。
- 复核者不得是被复核结论的产出者；关键结论要求第二来源复现后才采信。
- 验证标准预先写死，不允许执行者事后自行解释通过条件。
- 无法独立验证的断言标记"未证实"，不默认为真。

## 反模式信号

- "他说已经修好了"直接采信，链路里唯一没复验的就是这句。
- 默认持信任态度做验收——对抗性不足让虚假通过存活到后期。
