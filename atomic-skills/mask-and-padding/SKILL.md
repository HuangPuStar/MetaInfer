# 掩码与填充语义

**何时触发**：处理变长输入、分块填充、无效槽位、被掩蔽的位置。

## 规则

- 为无效/填充位置定义**唯一语义**（保持负无穷 / 置零 / 跳过），实现与参考两侧一致并注释——同一批次内混用两种语义是高频错源。
- 混合批次中短条目/无效槽位的输出显式掩蔽；填充值**禁止参与累加或归一化**。
- 比较时非法位置单独豁免，不与有效位置混算误差；豁免规则写明。
- 数值出现整体异常（如放大百倍）时，优先排查掩码漏贴与未初始化读取。

## 反模式信号

- "填充位用零乘一下就行"——零乘出的假数据流进了下游。
- 短序列没掩蔽，与长序列混合后结果偶发异常。
