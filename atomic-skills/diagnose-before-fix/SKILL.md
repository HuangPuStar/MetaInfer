# 修复前先诊断

**何时触发**：任何失败出现后的第一个动作。

## 规则

- 出错后的第一反应是回到侦察与测量，定位机制后再改；失败后大面积撤回重新探索同样是浪费——聚焦修复。
- 失败后的第一个动作**不得是重发与上次完全相同的命令**；重跑前至少改变一个要素（日志详细度、超时值、输入规模、诊断开关）。
- 没有指向明确机制的证据时，禁止凭直觉改代码；修复必须对应一个写下的根因，不对应"试一下看看"。
- 连续两次失败后，把"重跑"替换为"缩小复现"。

## 数据画像

- 超时后约两成轨迹逐字重跑同一命令，仅一成做任何编辑；错误应对的高频形态是"等待/重试"而不是"分类/诊断"。

## 反模式信号

- "失败→原样重跑→再失败"的循环。
- 改动对应的是"我觉得"而不是"证据显示"。
