# 主动报进度

**何时触发**：运行任何长任务、多轮实验、或可能出现阻塞的工作。

## 规则

- 长任务周期性主动给出四要素：正在做什么、已完成什么、卡在哪、下一步。
- 出现阻塞或方向性疑问**立即**上报，不默默绕行、不默默降级目标。
- 被问到"进展如何/汇报一下进展"本身就是一次失败信号——说明主动汇报缺失。
- 长时间静默后给出的"惊喜结果"比中途的坏消息更损害信任。

## 反模式信号

- 会话静默很久，操作者只能靠催获取状态。
- 遇到障碍自行改道，事后才（或从不上）说明。
